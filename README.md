# Cash is King! – Collectibles map / Sammelkarte

**▶ https://old-pitcher.github.io/cashisking_collectibles/**

*[Deutsch weiter unten](#deutsch)*

An interactive, to-scale top-down map of all collectibles in the game *Cash is King!*:

- 59 closed and 8 open packages
- 72 butterflies
- 44 graffiti, stains, dirt and posters

The map also shows a site plan of the town, built from the outlines of the scene objects.

## Features

- **Zoom and pan:** mouse wheel or double-click zooms, dragging pans the map.
- **Height:** the colour of each marker shows its height (Y).
- **Details on hover:** a marker shows its number, coordinates and scene path. The site plan shows the name of the topmost object.
- **Load your save game:** the map shows only what you are still missing, with a count per type. The file is read only in your browser. It is not uploaded anywhere and not stored.
  - Save game location on Windows: `%USERPROFILE%\AppData\LocalLow\Three River Games\Cash is King!\Save - Player`
  - File name: `Save Slot 0.savegame`
- **Languages:** German and English.
- **Offline:** a single HTML file without external dependencies, so it also works offline.

## Deutsch

Eine interaktive, maßstabsgetreue Draufsicht auf alle Sammelobjekte im Spiel *Cash is King!*:

- 59 geschlossene und 8 offene Pakete
- 72 Schmetterlinge
- 44 Graffiti, Flecken, Schmutz und Poster
